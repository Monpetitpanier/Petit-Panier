# 🧺 Petit Panier

> **Le compagnon qui veille sur ta charge mentale.**

Bienvenue dans **Petit Panier**.

Petit Panier est une application imaginée pour aider à déposer ses pensées, ses tâches, ses projets et ses émotions dans un endroit calme, chaleureux et rassurant.

Au cœur de cette maison veille **Fifi**, une petite chatte noire et blanche qui accueille chaque utilisateur avec douceur.

Notre mission :

> **Aider chacun à retrouver un peu de sérénité, une pensée après l'autre.**
